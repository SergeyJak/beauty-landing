# Скриншоты отзывов

Загрузите фотографии в эту папку в ветке `feat/client-testimonials` (PR #21).

Желательные имена: `01.jpg`, `02.jpg`, …, `23.jpg` — в порядке отправки в чат. Подойдут JPG, PNG и WebP. Если имена другие, сохраните порядок или добавьте пояснение.

Папка находится вне `public/`: приложение не раздаёт эти файлы посетителям сайта. Для сайта будут отдельно подготовлены обрезанные, оптимизированные копии в `public/reviews/`.

**Репозиторий GitHub публичный.** Сюда загружайте только изображения без персональных данных клиентов. Необезличенные исходники лучше передать ZIP-архивом в чат, чтобы скрыть имена, аватары и другие данные до добавления в GitHub. Удаление файла позднее не удаляет его из истории Git.

В GitHub откройте эту папку → **Add file → Upload files**, выберите фотографии и сохраните изменения в текущей ветке PR.
